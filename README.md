
# Educational Search Framework - Code and Dataset

## Contents
- `sample_educational_dataset.csv`: Sample educational dataset.
- `preprocessing.py`: Script to preprocess descriptions (tokenization, lemmatization, stopword removal).
- `model_training.py`: Script to train a basic neural network on processed text.
- `evaluation_metrics.csv`: Evaluation results.
- `README.md`: Project overview.

## Instructions
1. Run `preprocessing.py` to clean the dataset.
2. Run `model_training.py` to train a basic model.
3. Evaluation metrics are provided in `evaluation_metrics.csv`.

This repository supports the reproducibility of the paper: "Enhancing Learning through an Adaptive Web-Based Educational Search Framework Integrating NLP and Machine Learning Techniques."
